# PathBSR notebooks

These notebooks are interactive front-ends for the cleaned PathBSR workflow.

- `01_best_model_predict.ipynb`: run/check the current default PathBSR model.
- `02_path_count_analysis.ipynb`: inspect path-count buckets and generated figures.
- `03_cardinality_analysis.ipynb`: inspect relation cardinality buckets and generated figures.
- `04_router_analysis.ipynb`: per-relation validation-selected router and test-set complementarity analysis.
- `pathbsr_evaluation_protocol_tables.ipynb`: final evaluation protocol table export.

Canonical batch scripts remain in `scripts/`:

- `scripts/run_pathbsr.py`
- `scripts/structural_analysis.py`
- `scripts/pathbsr_experiments.py`
- `scripts/router_analysis.py`
